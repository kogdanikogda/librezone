# Макеты Figma — Libre.Zone 2.0

Файл: https://www.figma.com/design/8AzhfYFeMH3XJBfWboYR39/Libre.Zone-2.0

Экраны собраны заново по прототипу v3 (`prototype/`): каждый экран снят из прототипа в браузере
(светлая и тёмная тема, тот же DOM) и переведён в Figma автоматически — с auto layout, компонентами
и токенами. Скрипты конвейера лежат в `tools/figma-pipeline/`.

## Страницы
| Страница | Что внутри |
|---|---|
| Cover | Обложка 1920×1080: логотип, название, два экрана (светлый и тёмный) |
| Foundations | 81 цветовая переменная (образцы Light / Dark с HEX), 4 градиента, 80 текстовых стилей, 10 теней, отступы и радиусы |
| Icons | 42 иконки `Icon/<name>` |
| Components | 65 разделов: компоненты собраны в наборы вариантов (`Variant=…`), подписи на auto layout; отдельно — графика (логотип, монеты, сети, банки) |
| Screens | 35 экранов прототипа (верхний ряд — Light, нижний — Dark, та же структура с режимом Dark коллекции Color), прототип со ссылками |

## Экраны
01 Главная · 02 вне часов · 03 выбор криптовалюты · 04 уведомления · 05–08 вход (способ, номер, код, регистрация) ·
09–13 новый обмен (реквизиты, банк, заполнено, проверка, согласие) · 14–27 обмен (создан, оплата Сбер / Т-Банк,

## Как устроено
- Всё на auto layout (исключение — векторная графика). Отступы — padding, неравные зазоры — спейсеры, прижатие вправо — растягивающийся спейсер.
- Повторяющиеся элементы — экземпляры компонентов; различия — переопределения текста и замена иконок/графики.
- Цвета только из переменных `Color` (Light / Dark), тексты — из текстовых стилей, тени — из стилей эффектов, градиенты привязаны к переменным.
- Неразрывные пробелы после однобуквенных предлогов и союзов (как в прототипе).
- Прототип: таб-бар, колокольчик → уведомления, основной сценарий входа и обмена, профиль, правила; крестики шторок — «назад». Старт: «Libre.zone · Light» и «Libre.zone · Dark».

## Конвейер (`tools/figma-pipeline/`)
1. `states.py` — открывает прототип в Playwright, проходит 35 состояний, снимает DOM (`exp.js`) и скриншоты в двух темах.
2. `transform.py` + `tokens.py` — переводит DOM в дерево auto layout, подбирает токены и стили, находит компоненты.
3. `emit.py` — собирает полезную нагрузку по экранам (первое вхождение компонента создаёт его, дальше — экземпляры).
4. `compiler.js` — код, который строит узлы в Figma (хранится в файле и вызывается через Plugin API); `mkmulti.py` / `mkover2.py` готовят вызовы.
