# Как работать с проектом, чтобы тратить меньше токенов

## Прототип (prototype/)
- Исходники: `prototype/src/part1.html` (разметка и CSS) и `prototype/src/js/*.js` — модули по порядку номеров. Один `<script>` / одна IIFE, модули просто склеиваются.
- Сборка и проверка синтаксиса: `prototype/build.sh` → `prototype/libre-zone-v3.html`.
- Карта модулей (что где искать, читать только нужный файл):
  - `00-core.js` — хелперы, состояние `S`, данные (банки, монеты, курсы), `fresh()`, иконки
  - `10-calculator.js` — главная, калькулятор, чипы, карусели «безопасность»
  - `20-new-exchange.js` — создание обмена, индикатор шагов
  - `30-order.js` — экран заявки/оплаты, таймеры
  - `40-login.js` — вход
  - `50-sheets.js` — шторки и модалки
  - `60-typography.js` — типограф (`typo`, `typoTree`, MutationObserver)
  - `70-render-and-acts.js` — `render()`, `polish()`, обработчик `data-act`
- Правка: `grep -n "ключевое слово" prototype/src/js/*.js`, потом читать/править только найденные строки (Read с offset/limit, Edit). Не читать файл целиком и не печатать собранный HTML.
- Публикация: `Artifact` с тем же file_path и `edits` для маленьких правок.

## Проверка
- `node tools/proto-audit.js` — краулер: кликает по всем состояниям, ищет нарушения типографики. Печатает одну строку, если всё чисто.
- `node tools/proto-shot.js` — скриншот; смотреть только изменённый экран.

## Figma
- Правка точечная: брать нужный узел по id и менять только его; не обходить весь файл.
- Из `use_figma` возвращать только id и счётчики, не списки узлов.
- Скриншот один на изменённый экран, а не на все.
- Типографика Figma: правила те же, что в `60-typography.js`; пересканировать только изменённые узлы.

## Сессия
- Одна тема на сессию (Figma / прототип / документы). После этапа: лог → коммит → пуш, и новую тему начинать с нового чата, читая `docs/progress-log.md` и этот файл.
