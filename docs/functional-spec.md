# Libre.zone — функциональная спецификация и точки роста

2026-10-14 · @Alex

Libre.zone — это P2P-обменник рублей на криптовалюту и обратно с фиксированными суммами и курсом, который фиксируется при создании заявки. Документ описывает текущий функционал по принятым макетам Figma, находит точки роста и служит основой для нового, улучшенного продукта.

## Контекст

- **Что это.** Обмен RUB ↔ USDT (сети TRX и TON), USDC (Solana), BTC, ETH. Деньги по рублёвой стороне идут через банки РФ и СБП.
- **Как устроен обмен.** Пользователь выбирает одну из фиксированных сумм (50, 100, 1 000, 5 000, 10 000, 50 000 RUB). Цвет линии под суммой показывает, сколько встречных заявок уже есть в очереди. Чем их больше, тем быстрее пройдёт обмен.
- **Вход.** Только через Telegram: номер телефона, код из Telegram, затем обязательные ФИО и email.
- **Режим работы.** Обмены создаются с 10:00 до 18:30 GMT+3. Вне этого времени можно смотреть статусы уже созданных заявок.
- **Платформа.** Адаптивный web, mobile-first, с учётом запуска как Telegram Mini App. Языки: русский и английский. Тёмная тема входит в план.
- **Цели нового продукта.** Сохранить принятый клиентом дизайн как основу, поднять читаемость и доверие, снять лишние шаги в оформлении и сделать статусы заявки понятными без перехода в поддержку. Проект также готовится как кейс для портфолио.
- **Источник описания.** Макеты Figma (страница Showcase: Home, Login, Обмен, Детали обмена, Мои обмены, Профиль, Mobile Menu) и ответы заказчика на вопросы по функционалу.

## Роли и сценарии

В продукте пять ролей, и два основных сценария обмена зеркальны друг другу.

| Роль | Что делает | Ключевые экраны |
|---|---|---|
| Гость | Смотрит Главную, считает обмен, не может его создать без входа | Главная, Вход |
| Покупатель крипты | Отдаёт рубли банковским переводом, получает крипту на свой кошелёк | Новый обмен, Детали заявки |
| Продавец крипты | Отправляет крипту на адрес сервиса, получает рубли на карту или по СБП | Новый обмен, Детали заявки |
| Партнёр | Приглашает друзей по ссылке, видит статистику и выводит бонусы | Профиль партнёра, Вывод средств |
| Поддержка | Принимает обращения по проблемным заявкам | Чат в Telegram, support@libre.zone |

### Сценарий покупки крипты (рубли → крипта)

1. Выбрать валюту и сумму на Главной, нажать «Продолжить».
2. Войти через Telegram. Новый пользователь дополнительно вводит ФИО и email.
3. Выбрать банк отправки, указать адрес кошелька в нужной сети, принять правила, нажать «Обменять валюту».
4. Дождаться статуса «Ожидание платежа» и перевести рубли по показанным реквизитам. Перед переводом подтвердить, что имя получателя совпадает.
5. Приложить чек: ссылкой для Т-Банка, письмом на почту для остальных банков.
6. Дождаться проверки чека и поступления крипты. Заявка завершена.

### Сценарий продажи крипты (крипта → рубли)

1. Выбрать криптовалюту и сумму получения в рублях.
2. Выбрать банк получения и указать номер карты или телефона для СБП (для Т-Банка принимается и карта).
3. Отправить крипту на адрес сервиса в течение 10 минут.
4. Дождаться выплаты рублей. Если время вышло, заявка получает статус «Ошибка: не отправили средства».

## Функционал по экранам

В макетах есть четыре группы экранов по каждому размеру (mobile, tablet, desktop). Ниже дано поведение мобильной версии; на других размерах логика та же.

### Главная

- Hero: заголовок «Криптообмены с фиксированными суммами», подзаголовок, маскот.
- Карточка обмена: «Отдаю», чипы сумм, «Получаю», расчёт с курсом, кнопка «Продолжить». Пока не выбраны валюта и сумма, кнопка неактивна.
- Состояния: начальное, выбрана пара, выбрано количество, «Обмены сейчас недоступны» с спящим маскотом и ссылкой на «Мои обмены».
- Маркетинговые блоки: «Для любых задач» (4 карточки), «Почему Libre.zone?» (карусель преимуществ), «Наши партнёры» (логотипы мониторингов обменников).

### Вход и регистрация

- Модальное окно поверх Главной, пять шагов: ввод телефона, ввод кода из 6 цифр, повторная отправка кода (таймер 26 секунд), ошибка «Неверный или просроченный код», завершение регистрации (ФИО и email обязательны, данные нужны для KYC и проверки транзакций).

### Новый обмен

- Две карточки «Отдаю» и «Получаю», кнопка «поменять местами», выбор банка из списка с поиском по названию.
- **Рубли → крипта:** чипы сумм, банк отправки, адрес кошелька с проверкой формата (ошибка «Неверный адрес»), подсказка про веб-версию банка для подтверждения перевода.
- **Крипта → рубли:** чипы сумм в рублях, банк получения, номер карты или телефона («Номер указан неверно»), предупреждение, что сервис не несёт ответственности за неверные реквизиты.
- Чекбокс «Я соглашаюсь с правилами сервиса» и кнопка «Обменять валюту»: кнопка активна только при валидных данных и галочке.

### Детали заявки

- Шапка: номер заявки с копированием, статус, пара с суммами, курс.
- Состояния: создан, ожидание платежа (реквизиты с кнопками копирования, проверка имени получателя, чек), проверка чека, ожидание крипты, завершён с историей переводов.
- После завершения показывается окно реферальной программы: «Пригласи друга — получи скидку 10%».
- Кнопка «Отменить обмен» доступна до оплаты; подписка на уведомления об изменении статуса — в Telegram.

### Мои обмены

- Список карточек: номер, статус, пара с суммами, дата.
- Открытая заявка в трёх итогах: завершена (история переводов), ошибка, отменена.
- Четыре типа ошибок: «Вы не отправили средства», «Вы сообщили, что средства не получены», «Вы сообщили, что имя получателя не соответствует», «Чек не прошел проверку». Для трёх последних есть кнопка «Обратиться в поддержку».

### Профиль

- Пользователь: ФИО, email, телефон (телефон менять нельзя), режимы просмотра, редактирования и «Сохранено».
- Реферальная программа: друг получает купон $2 при обмене от 20 000 ₽, пригласивший получает скидку 10% на комиссию за каждого друга. Есть партнёрская ссылка и счётчики «Приглашённых друзей» и «Обменов со скидкой 10%».
- Профиль партнёра: раздел «Вывод средств» с состоянием «вывод выполнен». Детали нужно уточнить (см. открытые вопросы).

### Меню

- Полноэкранное меню из бургера: Новый обмен, Мои обмены, Мой профиль, Выйти. В макете также «Правила» и «Инструкции», но заказчик решил не включать их в работу (вместе с FAQ).
- Контакты: support@libre.zone, техподдержка 10:00–18:30 GMT+3, чат поддержки в Telegram, пометка об использовании Google reCAPTCHA.

## Бизнес-правила и статусы

Заявка на покупку и на продажу проходит по пяти статусам, и отличаются они третьим и чётвёртым шагом. Диаграмма ниже, после неё — правила и ошибки.

*[Диаграмма: статусы заявки · 2 сценария по 5 шагов — см. widget node/395bbd1f-cb08; описание: два сценария по 5 статусов, см. раздел «Бизнес-правила и статусы»]*

В покупке сервис ждёт перевод рублей и проверяет чек, в продаже проверяет поступившую крипту по AML и ждёт подтверждения получения рублей.

### Правила

| Правило | Как работает |
|---|---|
| Режим работы | Новые обмены только с 10:00 до 18:30 GMT+3. Вне режима Главная показывает «Обмены сейчас недоступны», статусы уже созданных заявок доступны |
| Фиксированные суммы | Сумма выбирается из чипов 50, 100, 1 000, 5 000, 10 000, 50 000 RUB. Другой суммы ввести нельзя |
| Очередь заявок | Линия под суммой: полная зелёная — много встречных заявок, короткая красная — мало, придётся ждать дольше. Иконка молнии означает быстрый обмен |
| Курс | Фиксируется при создании заявки, показывается с дробной частью до 8 знаков (например, 82.91497405 RUB) |
| Таймер | На перевод даётся 10 минут, на экране видны обратный отсчёт и полоса прогресса. В макете продажи он показан, для покупки нужно уточнить. Если не уложились, заявка отменяется и уходит в ошибку «Вы не отправили средства» |
| Имя получателя (покупка) | Перед переводом пользователь отвечает, совпадает ли имя получателя. Ответ «Нет» заканчивается ошибкой «Вы сообщили, что имя получателя не соответствует» |
| Чек (покупка) | Т-Банк: ссылка на чек в поле ввода. Другие банки: чек письмом на contact@libre.zone, потом кнопка «Чек отправлен». Для обоих способов есть ссылка на «инструкцию» |
| Веб-версия банка | Для части банков нужно подтверждать перевод в веб-версии банка, об этом предупреждает плашка «Почему?» |
| Реквизиты выплаты (продажа) | Для Т-Банка принимается номер карты или телефона, для остальных только телефон для СБП. Если номер неверный, поле красное с подписью «Номер указан неверно» |
| Подтверждение получения (продажа) | После проверки AML пользователя спрашивают: «Получены ли средства?». Если за 30 минут деньги не пришли, нужно обратиться в поддержку и назвать номер обмена |
| Отмена | Пользователь отменяет обмен кнопкой «Отменить обмен» через окно «Вы уверены, что хотите отменить обмен?» («Нет» или «Да») |
| Уведомления | В Telegram: подписка на статус заявки из экрана «Детали заявки»; есть отдельный экран «Напоминалка про подписку в боте» |

### Ошибки и отмена

| Состояние | Когда наступает | Что видит пользователь |
|---|---|---|
| Отменён вручную | Пользователь подтвердил отмену | Статус «Отменён» |
| Не отправил средства | Истёк таймер на 10 минут | Окно «Обмен отменён», после него статус «Ошибка» |
| Средства не получены | Пользователь ответил «Нет» на «Получены ли средства?» | Ошибка и кнопка «Обратиться в поддержку» |
| Имя получателя не совпало | Ответ «Нет» на проверку имени | Ошибка и кнопка «Обратиться в поддержку» |
| Чек не прошёл проверку | Чек отклонён | Ошибка и кнопка «Обратиться в поддержку» |

## Точки роста: функциональные идеи

Сильнее всего на конверсию влияют вход без кода, ясное время ожидания и быстрая связь с поддержкой. Всё ниже — гипотезы: они проверяются на данных заказчика и зависят от технических возможностей бэкенда.

| # | Идея | Что даёт | Зависит от | Приоритет |
|---|---|---|---|---|
| 1 | Вход в Telegram Mini App одним нажатием без кода | Убирает три из пяти шагов входа для тех, кто пришёл из Telegram | Поддержка Telegram initData на бэкенде | Высокий |
| 2 | Оценка времени обмена вместо цветной линии («около 5 минут») | Пользователь понимает последствие выбора суммы без расшифровки | Данные об очереди и истории сделок | Высокий |
| 3 | Итоговая сумма с расшифровкой комиссии и курса | Доверие и меньше обращений в поддержку | Решение заказчика, что и в какой форме показывать | Высокий |
| 4 | Уведомления о статусе включены по умолчанию, без кнопки «Подписаться» | Пользователь может закрыть экран и не терять обмен | Вход через Telegram уже даёт канал связи | Высокий |
| 5 | Поддержка одним нажатием с номером заявки, переданным в чат | При ошибках не нужно копировать номер вручную (сейчас нужно «предоставить идентификатор обмена») | Deep link в бота поддержки | Высокий |
| 6 | «Повторить обмен» из завершённой заявки и сохранённые реквизиты (адреса, банки, номера) | Повторный обмен за два касания | Хранение реквизитов, вопросы безопасности | Средний |
| 7 | Фильтры и поиск по «Моим обменам» (статус, дата, валюта), краткая причина ошибки в карточке | Удобная история при росте числа заявок | Объём истории на пользователя | Средний |
| 8 | Вне рабочего времени: «Сообщить, когда откроется» в Telegram | Не теряем интерес ночного трафика | Пуш-канал в Telegram | Средний |
| 9 | Реферальная ссылка с кнопкой «Поделиться в Telegram» и прогрессом друзей | Рост без рекламы | Сейчас ссылку нужно копировать вручную | Средний |
| 10 | Банки: показывать первыми популярные, запоминать последний выбор | Быстрее выбор банка, сейчас список по алфавиту | Статистика по банкам | Низкий |
| 11 | Страница статуса заявки по ссылке для поддержки | Поддержка видит то же, что пользователь | Права доступа, безопасность | Низкий |
| 12 | Аналитика воронки: Главная, выбор суммы, вход, создание заявки, завершение | Данные для тонкой настройки продукта и кейса | Согласие на сбор данных | Средний |

## Нефункциональные требования

Требования к платформе и качеству, без которых новый продукт нельзя считать завершённым. Значения в колонке «Целевое» — предложения, их нужно подтвердить с заказчиком.

| Область | Требование | Целевое |
|---|---|---|
| Платформа | Mobile-first веб-приложение, затем Telegram Mini App; планшет и десктоп — адаптация той же вёрстки | Mobile → Telegram → Tablet/Desktop |
| Производительность | Быстрая загрузка на мобильной сети, курс обновляется без перезагрузки страницы | Главная интерактивна за 3 секунды на 4G |
| Доступность | Размер текста не меньше 13 px, тап-зоны не меньше 44 px, контраст по WCAG AA, цвет не единственный носитель смысла | WCAG 2.1 AA |
| Темы | Светлая и тёмная тема, переключение «Авто / Светлая / Тёмная», все логотипы банков и сетей в двух вариантах | Обе темы с первого релиза |
| Языки | Русский и английский, все тексты в переменных, формат сумм и дат по локали | RU + EN |
| Безопасность | Подтверждение входа, защита реквизитов, журнал действий по заявке, проверка AML на стороне сервиса | Согласовать с заказчиком |
