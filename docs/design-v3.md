# Libre.zone v3 — дизайн-решения (обновлено 20.10.2026)

Прототип: https://claude.ai/artifact/3srsxuzKw9rpAL9WCpKMwS · файл `prototype/v3/libre-zone-v3.html`

## Запрос Alex
Новый прототип на основе принятого дизайна, но профессиональнее: градиент вместо плоского акцента, паттерны на фонах, продуманная форма обмена (блоки не должны менять размер формы), партнёры в едином оформлении без логотипов, роль «Партнёр» остаётся.

## Визуальное направление (итог)
Из трёх проб (Aurora, Ink, Paper) выбрана палитра **Индиго**: фиолетово-индиго градиент в калькуляторе и кнопках, светлая и тёмная темы (переключатель только «Светлая / Тёмная»). Блок безопасности «Почему обмен безопасен?» с тремя карточками и слайдером.

## Правила оформления (действуют для прототипа и Figma)
- **Сетка размеров:** шаг 4, значения 4, 8, 12, 16, 20, 24, 32, 40, 48. Отступы, радиусы, размеры элементов и высоты строк на сетке. Ширина экрана 390 px задаётся устройством и не подгоняется.
- **Равные отступы** от края блока: 16 px со всех сторон в плитках, карточках и окнах.
- **Типографика:** неразрывные пробелы после коротких предлогов и союзов, перед тире, в числах (тонкий неразрывный для тысяч), в номере телефона; висячих предлогов и разрывов слов нет, мягких переносов нет. Целые размеры шрифта, высота строки кратна 4.
- **Figma:** auto layout везде, повторяющееся — компоненты со свойствами, цвета и тексты только из переменных и стилей. Экраны в светлой и тёмной теме, 35 штук. Окна лежат поверх экрана (абсолютное позиционирование).

## Как показывается прототип
- Всегда в рамке iPhone (Dynamic Island, статус-бар, индикатор «домой»), экран внутри 390 px, рамка масштабируется под окно.
- Сервисный блок (тема, режим работы, таймер, вход, демо-сценарии, переходы) лежит в drawer справа, открывается по гамбургеру.
- На GitHub Pages: https://kogdanikogda.github.io/librezone/ , репозиторий https://github.com/kogdanikogda/librezone

## Анимации (переключатель в drawer: Выкл / Мягкие / Живые, по умолчанию «Живые»)
- Смена направления: старые строки уходят с лёгким уменьшением, новые появляются в другой позиции с лёгким увеличением, кнопка поворачивается на 180°.
- Выбор суммы: плитка плавно перекрашивается и «подпрыгивает», суммы досчитываются без перелёта (не ниже нуля), блок времени обмена стоит на месте, содержимое меняется фейдом.
- Учитывается системная настройка «уменьшить движение».

## Форма обмена
Причина «прыжков» в оригинале: два выпадающих списка с пустыми состояниями, суммы и банк появлялись только после выбора пары.
Решение:
1. Рубль всегда одна из сторон, поэтому выбирается только криптовалюта (список-шторка), направление меняется кнопкой «поменять местами».
2. Пара и сумма выбраны по умолчанию (USDT TRX, 5 000 ₽): пустых состояний нет.
3. Калькулятор на Главной имеет фиксированные слоты: две строки, сетка 3×2 с суммами, блок времени, строка курса, кнопка. Высота не меняется.
4. На экране «Новый обмен» два шага (Реквизиты → Проверка) с одинаковой структурой: банк и адрес/номер, зарезервированный слот под примечание и подсказку. Кнопка закреплена внизу.
5. Банк выбирается в шторке: популярные сверху, поиск.
6. Итоговая сумма и курс видны в верхней плашке. В деталях обмена под суммой одна строка: «1 USDT = 82,91 ₽ (с учётом комиссии)», сеть не указывается.

## Партнёры
Единая карточка: номер, название, роль («Мониторинг обменников» / «Анализатор обменников»), кнопка перехода, общий паттерн-фон. Логотипов нет.

## Улучшения из списка точек роста, вошедшие в v3
Вход через Telegram одним нажатием (запасной путь по телефону и коду), время обмена по размеру очереди вместо цветной линии (гипотеза: ≈ 3, 8, 20 мин), уведомления Telegram включены по умолчанию, «Повторить обмен» с подстановкой банка и реквизитов, фильтры в «Мои обмены», поддержка с номером заявки, кнопка «Поделиться в Telegram» в профиле, таймер 10 минут в покупке и продаже, степпер статусов.

## Статусы и правила продажи (по оригиналу)
Создан → Ожидание платежа (10 минут) → Проверка AML → Ожидание фиата → окно «Получены ли средства?» (30 минут) → Завершён. Отмена: подтверждение «Вы уверены?».

## Допущения для проверки
- Время обмена по очереди (3, 8, 20 минут) — гипотеза.
- Описания «Почему Libre.zone?» кроме «Курс фиксируется при создании обмена» — мои формулировки.
- Значки банков — буквы-заглушки.
